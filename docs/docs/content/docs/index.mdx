## 文档如何组织

- **Admin 是阅读起点**：从真实后台开发任务进入，不需要顺序读完整站。
- **架构解释协作关系**：说明能力应该放在哪一层，以及上下游如何连接。
- **包文档负责实现细节**：提供公共 API、类型、配置和源码入口。
- **独立组件站负责 Demo**：Web UI、Native UI 与 Playground 保持独立，通过统一导航互通。
