这一栏讲的是**仓库本身**：怎么把项目跑起来、包是怎么组织的、以及往里提交代码要遵守什么约定。

不涉及具体某个后台页面怎么写（那在 [Admin 应用](/docs/admin)），也不涉及某个包的 API 细节（那在 [包参考](/docs/packages)）。

## 第一次来看这里

按顺序读三篇就够上手了：

1. [项目简介与设计理念](/docs/guide/getting-started/introduction) —— 先理解为什么 `apps/admin` 这么「薄」
2. [快速开始](/docs/guide/getting-started/quick-start) —— Node 20+、pnpm 10.4.1，按目标启动 Admin、Web UI 或 Native UI
3. [目录结构总览](/docs/guide/getting-started/directory) —— 31 个包分别在哪、各自管什么

之后按你要做的事分流：改后台页面去 [Admin 应用](/docs/admin)，查某个 `@skyroc/*` 的 API 去 [包参考](/docs/packages)。
