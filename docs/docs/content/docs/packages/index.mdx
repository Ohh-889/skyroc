仓库把后台系统里反复出现的能力拆成了 **31 个独立包**。这一栏是它们的完整 API 参考。

想知道这些能力**在应用里怎么用**，去 [Admin 应用](/docs/admin)；想理解**为什么这么分层**，去 [架构设计](/docs/guide/architecture/package-layering)。

## 分层

依赖只能从上往下，同层之间不能互相依赖：

```text
应用层      apps/admin、apps/admin-example
              ↓
平台能力层  packages/web/*        （Web 专属：UI、主题、布局、Vite）
              ↓
基础设施层  packages/@core/*      （跨端运行时：请求、状态、日志、调度）
              ↓
类型层      packages/shared/*     （纯类型，零或极轻依赖）
```
