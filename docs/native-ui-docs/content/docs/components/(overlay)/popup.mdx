弹出层（Popup）是最基础的覆盖层组件，基于 `react-native-modal` 封装：五个弹出方向各自带默认进出场动画，容器负责遮罩、安全区、圆角与背景。`Dialog`、`ActionSheet` 等组件都建立在它之上。

```tsx
import { Popup } from '@skyroc/native-ui';
```

## 弹出位置

`position` 支持 `center`（默认）、`top`、`bottom`、`left`、`right`，每个方向都有对应的默认动画：

| 位置     | 进场           | 出场            | 容器尺寸     |
| -------- | -------------- | --------------- | ------------ |
| `center` | `fadeIn`       | `fadeOut`       | 由内容撑开   |
| `top`    | `slideInDown`  | `slideOutUp`    | 满宽         |
| `bottom` | `slideInUp`    | `slideOutDown`  | 满宽         |
| `left`   | `slideInLeft`  | `slideOutLeft`  | 满高、宽 75% |
| `right`  | `slideInRight` | `slideOutRight` | 满高、宽 75% |

<Demo src="@playground/popup/PopupPositions" />

## 何时使用

- 需要自己完全掌控弹层内容时用它。
- 标准的确认框用 `Dialog`，动作面板用 `ActionSheet`，可拖拽的底部面板用 `Sheet`。

## 圆角

`round` 统一控制五个方向的圆角，方向由 `position` 决定 —— 贴边的那一侧不加圆角（`bottom` 只有上方两角，`center` 是四角全圆）。

<Demo src="@playground/popup/PopupRound" />

## 容器背景

`surface`（默认 `true`）决定容器自身是否绘制背景。内容自带卡片时**必须传 `surface={false}`**：容器的不透明底铺满整个矩形，会盖在子节点圆角的外侧，把圆角原样填成直角，而且改子节点的 `className` 怎么都没用。

<Demo src="@playground/popup/PopupSurface" />

## 抽屉宽度

`left` / `right` 默认 `w-3/4`（不给宽度会被内容撑成任意宽）。`cn` 底层是 tailwind-merge，直接传 `className="w-1/2"` 即可覆盖。

<Demo src="@playground/popup/PopupDrawer" />

## 安全区避让

`safeAreaInsetTop` / `safeAreaInsetBottom` 分别避让状态栏（刘海）与 home indicator。

<Demo src="@playground/popup/PopupSafeArea" />

两者走的是 uniwind 的 `pt-safe` / `pb-safe`，而不是读 `SafeAreaInsetsContext`：安全区尺寸由应用根节点的 `Uniwind.updateInsets` 同步进运行时，不依赖弹层所在的 React 树里有没有 `SafeAreaProvider` —— 弹层挂在原生 Modal 里，context 本来就未必接得上。

## 关闭与遮罩

`closeOnBackdropPress` 与 `closeOnBackPress`（Android 硬件返回键）是**独立**的两个开关：无遮罩可点时不至于无路可退。两者都通过 `onUpdateShow(false)` 通知外部 —— 组件本身不持有显隐状态。

<Demo src="@playground/popup/PopupBackdrop" />

`backdropColor`（默认 `'#000'`）与 `backdropOpacity`（默认 0.4）自定义遮罩。

## 动画

`animation` 覆盖该位置的默认动画，只传一个方向时另一个方向仍走默认值；`duration` 是进出场时长（默认 300ms）。动画名取自 `react-native-animatable`。

<Demo src="@playground/popup/PopupAnimation" />

## 生命周期

`onOpened` / `onClosed` 都在对应动画结束后触发。

<Demo src="@playground/popup/PopupLifecycle" />

## 与 Toast 共存

原生 Modal 会盖住一切，包括 `Portal` 渲染的 `Toast`。需要两者共存时传 `coverScreen={false}` 让弹层就地渲染（该属性透传给 `react-native-modal`）。

<Demo src="@playground/popup/PopupInline" />

## API

### Popup
