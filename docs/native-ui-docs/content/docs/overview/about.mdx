## 为什么会有这个库

市面上的 React Native 组件库，用起来总有些地方不顺手：主题体系和业务割裂、组件 API 各成一套、样式定制要么改不动要么只能整个覆盖、原生交互细节（按下态、安全区、键盘避让）得在业务页面里反复补齐。

`@skyroc/native-ui` 是把这些踩过的坑重做一遍的结果：

- **来自真实业务。** 作者在上一家公司从 0 封装过公司内部的 React Native 组件库，基于 Design Token 沉淀了 40+ 基础与业务组件，支撑多个线上项目；这个库是那套经验的公开重构版。
- **和 Web 端同源。** 设计令牌与 `@skyroc/web-ui` 共用 `@skyroc/tailwind-plugin`，同一个产品的 App 端和管理后台不用维护两套色板。
- **原生行为进默认值。** 44pt 触摸热区、按下态、安全区、底部面板的手势与档位，都收进组件默认行为，而不是留给调用方。

它是 [Skyroc](https://github.com/Ohh-889/skyroc) 这个 Monorepo 的一部分，和 Web UI、管理后台物料、请求层、脚手架共享同一套工程基建。
