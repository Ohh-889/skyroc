## 2. 产品结论：首期拆成两个页面

OSS 管理包含两个权限等级和风险完全不同的业务域，首期必须拆成两个独立页面：

| 页面 ID | 页面         | 路径                       | 菜单可见 | 主要用户             | 核心任务                         |
| ------- | ------------ | -------------------------- | -------- | -------------------- | -------------------------------- |
| OSS-001 | 文件管理     | `/system/oss`              | 是       | 业务管理员、内容运营 | 上传、查找、预览、下载、删除文件 |
| OSS-002 | 存储配置管理 | `/system/oss-config/index` | 否       | 平台管理员、运维人员 | 维护桶连接、密钥和默认存储       |

不再额外拆路由的子流程：

- 上传文件：在 `OSS-001` 中使用上传抽屉。
- 文件预览：在 `OSS-001` 中使用预览抽屉或灯箱。
- 文件删除：使用危险操作确认弹窗。
- 新增/编辑存储配置：在 `OSS-002` 中使用宽抽屉。
- 设置默认存储：使用影响确认弹窗。
- 删除存储配置：使用高风险确认弹窗。

不采用“文件 / 配置”两个页签放在同一个页面，原因是：

1. 文件权限是 `system:oss:*`，配置权限是 `system:ossConfig:*`，不能因为能上传文件就看见 AccessKey。
2. 文件管理是高频内容任务，配置管理是低频基础设施任务，信息密度和风险提示不同。
3. 配置页面包含密钥和桶权限，必须拥有独立路由门禁、操作审计和会话访问控制。
4. 独立页面可以让配置页保持隐藏菜单，同时通过面包屑和返回入口回到文件管理。

## 3. 架构结论

OSS 模块不是浏览对象存储桶的通用客户端，而是“业务文件记录 + 存储连接配置”的管理入口：

```text
文件管理
  → 查询 sys_oss 元数据
  → 使用记录中的 service 找到原存储配置
  → 预览 / 下载 / 删除真实对象

上传文件
  → 选择当前租户默认存储配置
  → 服务器中转上传对象
  → 写入 sys_oss 元数据

存储配置管理
  → 维护 endpoint、bucket、AccessKey、SecretKey
  → 选择一条默认配置
  → 影响后续上传位置
  → 不改变历史文件记录中的 service
```

职责边界：

- 前端负责筛选、分页、上传交互、预览呈现、危险操作确认、权限显隐和请求结果反馈。
- FastAPI 文件服务负责租户隔离、上传大小校验、对象 key 生成、默认配置解析、文件流转发和对象/记录删除。
- FastAPI 配置服务负责配置名唯一性、默认配置切换、内置配置保护、缓存失效和密钥不出参。
- 对象存储设施层负责连接 MinIO/S3 兼容服务、读取、上传、删除和私有地址签名。
- 用户模块尚未向 OSS 列表补充上传人姓名，因此前端只能可靠展示 `createBy` 用户主键。
- 操作日志记录上传、删除、配置新增、配置修改、默认切换和配置删除；下载不记录操作日志。

## 4. 已知事实与设计假设

### 4.1 RuoYi 前端事实

文件管理参考页包含：

- 按文件名、原名、文件后缀、创建时间和服务商筛选。
- 表格展示文件名、原名、后缀、文件地址、创建时间、上传人和服务商。
- 上传文件、上传图片、下载、单个删除和批量删除。
- 图片文件在列表中显示缩略图，并可切换是否预览列表资源。
- 从文件页进入独立的配置管理页面。
- 创建时间和服务商支持服务端排序。

存储配置参考页包含：

- 按配置 key、桶名称和是否默认筛选。
- 表格展示访问站点、自定义域名、桶、前缀、区域、访问策略和默认状态。
- 新增、编辑、单个删除、批量删除和默认状态切换。
- 编辑表单包含 AccessKey、SecretKey、HTTPS、桶权限和区域等连接字段。

本文使用以上能力确认业务覆盖面，但不照搬以下交互：

- 不把默认配置做成可随手关闭的行内开关。
- 不在表格中展示完整 AccessKey，更不展示 SecretKey。
- 不用两个按钮重复打开相同上传接口；首期统一为一个“上传文件”入口，再根据文件类型决定预览方式。
- 不把完整 URL 作为表格主内容长期铺开，避免表格被长链接挤占。
- 不把“预览开关”写回全局参数；列表预览作为用户界面偏好处理。

### 4.2 当前 FastAPI 文件接口事实

当前文件能力已经实现：

- 分页查询文件，兼容 `current/size` 和 `pageNum/pageSize`。
- 按多个 ID 查询文件，供其他业务页面回显附件。
- 单文件上传，响应 HTTP `201`。
- 服务器中转下载，响应二进制流而不是 `R` 信封。
- 单个或批量删除，ID 使用逗号分隔路径参数。
- 文件名和原名模糊匹配；后缀、URL、服务配置和上传人等值匹配。
- 创建时间范围查询和白名单字段排序。
- 默认上传上限为 `50 MiB`，但部署环境可以修改，前端不能把该数值当成永久契约。
- 私有桶列表 URL 是 120 秒临时地址，前端不得持久化或长期缓存。
- 文件内容不进数据库，数据库只保存对象 key、原始名称、后缀、URL、服务配置名和扩展信息。

当前文件接口尚未实现：

- 文件详情专用接口。
- 重命名、移动、复制、替换和分享链接。
- 文件夹或目录树。
- 上传分片、断点续传、秒传和内容去重。
- 前端直传对象存储。
- 导入、导出或文件元数据编辑。
- 上传人姓名聚合。
- 结构化的文件大小和 MIME 字段；当前只在 `ext1` JSON 字符串中保存。

### 4.3 当前 FastAPI 配置接口事实

当前配置能力已经实现：

- 配置分页、详情、新增、整条修改、默认状态变更和批量删除。
- 配置 key 在当前租户内唯一。
- 配置 key 必须以字母开头，只能包含字母、数字、下划线和连字符。
- `endpoint` 不能包含 `http://` 或 `https://`，协议由 `isHttps` 决定。
- 新增或修改为默认配置时，原默认配置在同一事务中自动让位。
- 配置修改后清理 Redis 配置缓存和默认配置缓存。
- 响应永远不包含 `secretKey`，编辑时必须重新输入密钥。
- ID 为 `1`、`2`、`3`、`4` 的内置配置不能删除。
- 文件历史记录保存的是配置 key，修改默认配置不会迁移历史文件。

当前配置接口的已知风险与缺口：

- 后端允许取消最后一条默认配置，之后上传会失败为服务端错误。
- 后端只保护四条内置配置，没有检查普通配置是否仍被历史文件引用。
- 后端允许删除非内置的当前默认配置，可能导致后续上传失败。
- 没有“测试连接”“检查桶”“引用文件数”或“删除影响摘要”接口。
- AccessKey 仍在响应中返回；前端必须默认遮罩，长期应评估后端是否也只返回脱敏值。
- SecretKey 在数据库和 Redis 中为明文，配置权限必须视为对象存储写权限。

### 4.4 设计假设

- 文件列表是日常主工作区，默认使用表格模式。
- 图片预览只根据可识别后缀和可用 URL 展示；加载失败退化为普通文件图标。
- 文件 URL 只用于即时预览，不写入本地存储，不复制为永久分享链接。
- 首期上传一次选择一个文件，与当前后端单文件接口一致。
- “服务商”实际保存的是 `configKey`，界面名称使用“存储配置”，避免误以为只能填写云厂商品牌。
- 配置页不提供“取消默认”操作，只允许把另一条配置“设为默认”。
- 当前默认配置不提供删除入口；内置配置也不提供删除入口。
- 在后端增加引用检查前，删除普通存储配置必须展示历史文件失联风险。
- 配置页只对具备 `system:ossConfig:list` 的用户开放；普通文件管理员无需看到该入口。

## 5. 用户与目标

### 5.1 业务管理员 / 内容运营

目标：

1. 找到业务中已上传的文件。
2. 上传一份新附件或图片。
3. 快速确认图片内容或文件基础信息。
4. 下载需要保留或核对的文件。
5. 删除错误、过期或不应继续保存的文件。

不需要了解：

- AccessKey、SecretKey。
- Bucket、Endpoint、Region 等基础设施配置。
- Redis 缓存和对象存储连接方式。

### 5.2 平台管理员 / 运维人员

目标：

1. 查看当前租户使用哪些存储配置。
2. 新增或更新一套对象存储连接。
3. 安全地轮换密钥。
4. 将另一套配置设为默认，使后续上传切换目标桶。
5. 识别并处理失效或不再使用的配置。

需要明确知道：

- 修改配置会影响该配置下历史文件的预览、下载和删除。
- 设置默认只影响后续上传，不迁移历史对象。
- SecretKey 保存后无法再次读取，编辑时必须重新输入。

### 7.3 查询区

| 条件      | 控件         | 请求字段               | 匹配方式 | 规则                              |
| --------- | ------------ | ---------------------- | -------- | --------------------------------- |
| 文件名称  | 文本输入框   | `fileName`             | 模糊     | 对象 key，最多 255 字符           |
| 原始名称  | 文本输入框   | `originalName`         | 模糊     | 用户上传时的文件名，最多 255 字符 |
| 文件后缀  | 可输入下拉框 | `fileSuffix`           | 精确     | 建议统一为带点格式，如 `.png`     |
| 存储配置  | 可搜索下拉框 | `service`              | 精确     | 值为配置 key，不等同于固定云厂商  |
| 上传人 ID | 数字输入框   | `createBy`             | 精确     | 当前接口没有姓名搜索              |
| 创建时间  | 日期时间范围 | `beginTime`、`endTime` | 范围     | 开始时间不得晚于结束时间          |

查询行为：

- 点击“查询”或在文本框按 Enter 请求数据。
- 修改条件不自动发请求。
- 新查询重置到第 1 页。
- 重置清空筛选、排序和选择状态。
- 查询参数写入 URL，返回页面后恢复。
- 默认排序为创建时间倒序；允许按创建时间、服务配置、文件名、原名和后缀排序。
- 分页统一使用 `current/size`，响应读取 `records/current/size/total`。

### 7.4 文件表格

| 列          | 默认显示 | 内容与规则                                                           |
| ----------- | -------- | -------------------------------------------------------------------- |
| 选择        | 是       | 有删除权限时显示；批量操作只作用于当前选中 ID                        |
| 文件        | 是       | 图片缩略图或文件类型图标、原始名称、对象 key；原始名称是主要识别信息 |
| 类型 / 大小 | 是       | 后缀 + 可解析的 `ext1.fileSize`；解析失败显示后缀和 `--`             |
| 存储配置    | 是       | 显示 `service` 配置 key                                              |
| 上传人      | 是       | 当前显示 `#createBy`；没有值显示“未知”                               |
| 创建时间    | 是       | `YYYY-MM-DD HH:mm`；支持排序                                         |
| 文件地址    | 否       | 列设置后可显示截断 URL；不默认展示完整长链接                         |
| 操作        | 是       | 预览/查看、下载、删除；最多两个直接操作，其余进入“更多”              |

文件列规则：

- `.png`、`.jpg`、`.jpeg` 等可识别图片显示 48px 缩略图。
- 缩略图请求失败后显示图片文件图标，不循环重试。
- PDF、文档、压缩包和未知类型使用不同的文件类型图标，但状态不能只靠颜色区分。
- 对象 key 使用次要文字并省略，Tooltip 显示完整值。
- `ext1` 是非结构化 JSON 字符串，解析必须容错，不能因为一行脏数据让整个页面崩溃。

### 7.5 上传文件抽屉

触发条件：具备 `system:oss:upload`。

结构：

```text
上传文件
├── 上传说明
│   ├── 文件将上传到当前租户默认存储
│   └── 实际大小限制以服务端为准
├── 拖拽 / 选择文件区域
├── 待上传文件摘要
│   ├── 文件名
│   ├── 类型
│   └── 大小
├── 上传进度 / 提交状态
└── 取消 / 开始上传
```

规则：

- 首期一次只选择一个文件，对应 `POST /resource/oss/upload` 的单文件契约。
- 选择文件后显示名称、类型和大小，用户确认后才上传。
- 空文件由后端返回 400，提示“上传文件不能为空”。
- 超过部署限制返回 413，提示“文件超过系统允许的大小，请选择更小的文件”。
- 没有默认存储时后端返回通用服务错误，界面提示“当前存储配置不可用，请联系管理员”，不暴露内部连接信息。
- 上传中禁用重复提交；关闭抽屉前需要确认是否取消。
- 上传成功关闭抽屉、刷新第 1 页并高亮新记录。
- 上传响应中的 `fileName` 是原始文件名，不是对象 key；前端不能与列表字段同名语义混淆。
- 不承诺断点续传、后台续传或刷新后恢复上传。

### 7.6 文件预览 / 查看抽屉

文件管理没有详情接口，首期直接使用列表行数据展示，不新增独立详情路由。

展示内容：

- 图片：大图预览，支持缩放、旋转和适配窗口。
- 非图片：文件类型图标和“暂不支持在线预览”说明。
- 原始文件名、对象 key、后缀、文件大小、MIME、存储配置、上传人 ID、创建时间。
- 下载按钮。
- 有删除权限时显示删除入口，但与下载保持视觉分离。

安全规则：

- 私有桶 URL 约 120 秒后失效，不显示“复制永久链接”。
- 打开过期预览时刷新列表或重新查询该 ID，而不是继续使用持久化缓存中的旧 URL。
- 不在新窗口直接渲染未知 `text/html`；下载接口始终按附件返回。
- 非图片不使用 iframe 直接加载第三方内容。

### 7.7 下载

- 具备 `system:oss:download` 时显示下载操作。
- 请求 `GET /resource/oss/download/{ossId}`。
- 该接口返回二进制流，不读取 `R.code`、`R.msg` 或 `R.data`。
- 文件名从 `Content-Disposition` 获取，兼容中文文件名。
- 下载中显示行级状态，避免用户连续点击产生多个下载。
- 404 时提示“文件已不存在”，刷新当前页。
- 下载不生成永久外链，也不把列表 URL 当作下载地址。

### 7.8 删除与批量删除

触发条件：具备 `system:oss:remove`。

单个删除确认：

```text
删除“合同.pdf”？
该操作会同时删除文件记录和对象存储中的真实文件，删除后无法恢复。
[取消] [删除文件]
```

批量删除确认：

```text
删除已选择的 8 个文件？
文件将从各自原存储中删除。若其中任一记录已变化，本次操作可能失败并需要刷新列表。
[取消] [删除 8 个文件]
```

规则：

- 请求路径为 `/resource/oss/{id1,id2,id3}`。
- 不把文件 URL、对象 key 或文件名拼进删除路径。
- 删除成功后清空选择，保持当前筛选；当前页为空时回退一页。
- 后端发现任一 ID 不存在时整批拒绝，界面提示“列表数据已变化，请刷新后重试”。
- 对象存储删除过程中可能出现部分对象已删、数据库记录仍在；失败时不能显示“全部未变化”，应提示刷新并联系管理员核对。
- 不提供回收站或恢复承诺。

### 7.9 页面状态

首次空状态：

```text
还没有文件
上传第一份文件后，可以在这里统一预览、下载和管理。
```

筛选无结果：

```text
没有找到符合条件的文件
尝试调整文件名称、后缀、存储配置或创建时间。
```

其他状态：

- 首次加载使用表格骨架屏。
- 翻页和排序保留表头与旧数据，表格进入局部加载状态。
- 列表请求失败显示页内错误和“重新加载”。
- 某一缩略图失败只影响该行，不升级为整页错误。
- 无列表权限时由路由展示 403，不渲染空表格。

### 8.3 查询区

| 条件     | 控件       | 请求字段     | 匹配方式 | 规则             |
| -------- | ---------- | ------------ | -------- | ---------------- |
| 配置名称 | 文本输入框 | `configKey`  | 精确     | 最多 20 字符     |
| 桶名称   | 文本输入框 | `bucketName` | 模糊     | 最多 255 字符    |
| 默认状态 | 单选下拉框 | `status`     | 精确     | 全部、默认、备用 |

界面文案使用“默认 / 备用”，请求值映射为：

| 界面状态 | 请求值 | 含义         |
| -------- | ------ | ------------ |
| 默认     | `0`    | 当前默认存储 |
| 备用     | `1`    | 非默认存储   |

前端不直接向用户展示“0 是启用、1 是停用”这种反直觉实现细节。

### 8.4 配置表格

| 列        | 默认显示 | 内容与规则                                                     |
| --------- | -------- | -------------------------------------------------------------- |
| 选择      | 否       | 首期不做批量删除，降低配置误删风险                             |
| 配置      | 是       | 配置 key、备注；内置配置显示“系统内置”标签                     |
| 访问地址  | 是       | 根据 `isHttps + endpoint` 组合显示；自定义域名单独作为次要信息 |
| 桶 / 前缀 | 是       | 桶名称为主，前缀为空显示“无前缀”                               |
| AccessKey | 是       | 默认仅显示前 2 位和后 4 位的遮罩值，不提供表格复制             |
| 桶权限    | 是       | 私有 `private`、公开 `public`、自定义 `custom`                 |
| 区域      | 是       | `region` 为空显示“未设置”                                      |
| 状态      | 是       | “默认”或“备用”标签，不使用行内开关                             |
| 创建时间  | 否       | 列设置后可显示                                                 |
| 操作      | 是       | 编辑、设为默认、删除；按状态和权限动态显示                     |

行操作规则：

- 当前默认行不显示“取消默认”，只显示“默认”状态。
- 备用配置且具备编辑权限时显示“设为默认”。
- 内置配置不显示删除。
- 当前默认配置不显示删除。
- 普通备用配置具备删除权限时可显示删除，但必须进入高风险确认。
- 没有新增/编辑/删除权限时，页面退化为只读配置列表。

### 8.5 新增 / 编辑配置抽屉

抽屉宽度建议 720px，分为“标识与连接”“访问凭证”“桶行为”“说明”四个区块。

#### 标识与连接

| 字段       | 请求字段    | 必填 | 规则                                                          |
| ---------- | ----------- | ---- | ------------------------------------------------------------- |
| 配置名称   | `configKey` | 是   | 2–20 字符；字母开头；仅字母、数字、下划线、连字符；租户内唯一 |
| HTTPS      | `isHttps`   | 是   | 是 `Y` / 否 `N`；用开关或单选表达，不显示原始值               |
| 访问站点   | `endpoint`  | 是   | 2–255 字符；不能带 `http://` 或 `https://`                    |
| 自定义域名 | `domain`    | 否   | 最多 255 字符；是否带协议需按后端连接实现确认，不擅自自动改写 |
| 区域       | `region`    | 否   | 最多 255 字符                                                 |

访问站点输入框前缀实时显示 `http://` 或 `https://`，但前缀不进入 `endpoint` 请求字段。

#### 访问凭证

| 字段      | 请求字段    | 必填 | 规则                                       |
| --------- | ----------- | ---- | ------------------------------------------ |
| AccessKey | `accessKey` | 是   | 2–255 字符；密码型输入；默认遮罩           |
| SecretKey | `secretKey` | 是   | 2–255 字符；密码型输入；编辑时必须重新输入 |

安全规则：

- SecretKey 不从详情接口回显，不提供“恢复原值”。
- 编辑抽屉打开后 SecretKey 保持空白，并明确标注“保存修改需要重新输入当前或新密钥”。
- AccessKey 虽然当前接口返回完整值，界面默认遮罩，只有在编辑表单内允许主动查看。
- 密钥不写入 URL、日志、埋点、本地存储或普通错误消息。
- 密钥字段关闭浏览器自动填充，复制能力仅在用户主动操作时提供。

#### 桶行为

| 字段       | 请求字段       | 必填 | 规则                           |
| ---------- | -------------- | ---- | ------------------------------ |
| 桶名称     | `bucketName`   | 是   | 2–255 字符                     |
| 对象前缀   | `prefix`       | 否   | 最多 255 字符                  |
| 桶权限     | `accessPolicy` | 是   | 私有 `0`、公开 `1`、自定义 `2` |
| 保存后默认 | `status`       | 否   | 选中发送 `0`，未选中发送 `1`   |

桶权限说明：

- 私有：列表中的访问地址是短期签名地址，适合受控附件。
- 公开：对象 URL 可直接访问，适合公开资源。
- 自定义：桶策略由运维维护，系统不自动配置桶策略。

#### 说明

| 字段 | 请求字段 | 必填 | 规则          |
| ---- | -------- | ---- | ------------- |
| 备注 | `remark` | 否   | 最多 500 字符 |

`ext1` 首期不在表单中开放。它是后端保留扩展字段，没有稳定产品语义。

#### 保存行为

- 新增调用 `POST /resource/oss/config`，成功为 HTTP `201`。
- 编辑调用 `PUT /resource/oss/config`，请求必须带 `ossConfigId`。
- 保存为默认时需要二次确认：“后续上传将切换到此配置，历史文件不会迁移。”
- 配置 key 冲突返回 409，在配置名称字段下显示“配置名称已存在”。
- endpoint 带协议头返回 422，在访问站点字段下显示校验错误。
- 当前没有连接测试接口，界面不能伪造“连接成功”；保存成功只表示配置已写入。
- 保存成功关闭抽屉并刷新列表，不在成功消息中回显密钥。

### 8.6 设置默认存储

交互使用明确按钮和确认弹窗，不使用可关闭的行内开关。

```text
将“aliyun-prod”设为默认存储？

之后上传的新文件将写入该配置对应的桶。
当前默认配置会自动变为备用，历史文件仍保留在原存储中。

[取消] [设为默认]
```

规则：

- 调用 `PUT /resource/oss/config/changeStatus`。
- 请求体只提交 `ossConfigId` 和 `status: "0"`。
- 不提交 AccessKey、SecretKey、configKey 或其他配置字段。
- 成功后刷新配置列表和文件页使用的配置选项缓存。
- 页面不提供 `status: "1"` 的“取消默认”入口，避免出现零默认配置。
- 后端仍需补充“至少保留一条默认配置”的业务保护，前端约束不是安全边界。

### 8.7 删除存储配置

删除规则：

- 系统内置配置 ID `1–4` 不可删除。
- 当前默认配置不提供删除入口。
- 普通备用配置删除前展示配置名称、桶名称和不可恢复提示。
- 首期不提供批量删除，避免一次破坏多个历史文件来源。
- 删除调用 `DELETE /resource/oss/config/{ossConfigId}`。
- 后端返回 409 时展示具体业务文案，不把它转成普通成功。

高风险提示：

```text
删除存储配置“archive-s3”？

如果历史文件仍引用该配置，这些文件将无法预览、下载或删除。
当前系统还不能自动显示引用文件数量，请先确认配置不再使用。

请输入配置名称 archive-s3 以确认删除。
[取消] [删除配置]
```

生产可用前的后端要求：

- 删除时检查是否为当前默认配置。
- 删除时检查 `sys_oss.service` 是否仍引用该配置 key。
- 返回结构化阻塞原因和引用数量。

在这三项后端保护完成前，配置删除属于已知高风险能力。

### 8.8 页面状态

首次空状态：

```text
还没有存储配置
至少创建并设置一条默认配置后，文件上传才能正常工作。
```

异常状态：

- 没有默认配置：页面顶部显示 Error 警报“当前没有默认存储，文件上传不可用”，并突出“设为默认”操作。
- 配置列表失败：显示页内错误，不显示空状态。
- 配置详情 404：关闭编辑抽屉，刷新列表并提示“配置已不存在”。
- 409：保留表单内容，定位到冲突字段或删除阻塞原因。
- 422：将字段错误映射到对应表单项，未知错误显示表单顶部摘要。
- 无权限：路由级 403。

## 11. 关键业务规则

### 11.1 租户隔离

- 文件和存储配置都按当前租户隔离。
- 前端不提交 `tenantId`，也不能通过筛选切换租户。
- 不同租户可以使用相同配置 key，但同一租户内必须唯一。
- Redis 配置缓存按租户隔离，页面不展示缓存 key。

### 11.2 上传目标

- 上传永远使用当前租户的默认配置。
- 默认配置状态值为 `0`，不是常见的 `1`。
- 变更默认配置只影响后续上传。
- 历史文件下载和删除继续使用其 `service` 指向的配置。

### 11.3 对象 key

- 对象 key 由后端生成，结构为 `前缀/租户/年/月/日/uuid.后缀`。
- 前端不能提交或修改对象 key。
- 文件重命名只会涉及展示名还是对象 key 尚无接口，首期不提供。

### 11.4 私有文件

- 私有文件列表 URL 是短期签名地址。
- URL 有效期不等于用户会话有效期，不能转发为永久分享链接。
- 正式下载必须走受权限保护的下载接口。
- Query 缓存不能让临时 URL 在过期后继续作为有效地址使用。

### 11.5 删除一致性

- 文件删除先删对象，再删数据库记录。
- 配置删除会让历史文件失去连接信息，风险高于普通数据删除。
- 前端确认不能替代后端引用检查和事务保护。
- 所有删除成功后都要重新请求服务端数据，不能只在本地乐观移除。

## 12. 响应式与可访问性

### 12.1 中等宽度

- `992px–1199px` 查询区只保留原始名称、后缀、存储配置和查询按钮。
- 文件表格隐藏上传人和文件地址列。
- 配置表格隐藏 AccessKey 和创建时间列。
- 表格允许横向滚动，操作列保持固定。

### 12.2 窄屏

- `< 768px` 只保证文件查询、预览和下载。
- 上传抽屉占满屏幕，复杂存储配置编辑提示在桌面端完成。
- 配置表格维持最小宽度并横向滚动，不改成难以比较的卡片流。
- 危险操作确认不因屏幕变窄而省略影响说明。

### 12.3 可访问性

- 所有图标按钮具有可读名称和 Tooltip。
- 文件类型、默认状态、桶权限不能只用颜色表达。
- 上传拖拽区支持键盘聚焦和 Enter/Space 选择文件。
- 预览大图提供可关闭的替代文本和键盘退出方式。
- 表单错误与字段关联，提交失败后焦点移到第一个错误字段。
- 确认弹窗默认焦点放在取消按钮；危险按钮使用 Error 语义。
- 表格排序状态向辅助技术暴露。

## 13. 数据缓存与性能

- 文件列表和配置列表使用独立 TanStack Query key。
- 查询条件、页码、排序变化进入 query key。
- 文件列表的 `staleTime` 必须短于私有 URL 失效期，建议不超过 60 秒。
- 不把文件 URL、AccessKey 或表单密钥持久化到 localStorage。
- 上传、删除、配置新增/修改/设默认后使对应列表缓存失效。
- 图片缩略图使用固定尺寸和懒加载，避免整页同时加载原图。
- 列表每页最多 100 条，默认 10 或 20 条。
- 下载使用流式响应，不先将整个文件读入浏览器内存后再生成下载。

## 14. 审计与安全

后端当前记录：

- 文件上传。
- 文件删除。
- 配置新增。
- 配置修改，排除 `secretKey`。
- 默认状态修改。
- 配置删除。

后端当前不记录：

- 文件列表查询。
- 文件下载。
- 配置列表和详情查询。

前端要求：

- 不在埋点中记录 AccessKey、SecretKey、完整对象 URL 或完整文件名。
- 操作失败消息不拼接密钥和内部异常堆栈。
- 配置修改成功只显示配置名称和结果，不显示凭证。
- 下载行为如未来需要审计，应由后端建立专门审计策略，不能只靠前端事件。

## 17. 验收标准

### 17.1 页面与导航

- 文件管理和存储配置是两个独立路由页面。
- 配置页面不出现在普通侧边栏，进入后仍激活文件管理菜单。
- 无配置权限的用户看不到配置入口，直接访问返回 403。
- 返回文件管理后保留原筛选、分页和排序。

### 17.2 文件管理

- 能按原始名称、对象 key、后缀、存储配置、上传人和时间查询。
- 列表正确读取 `records/current/size/total`。
- 图片缩略图失败不影响整页。
- 上传成功后能定位新记录；空文件、超限和缺少默认配置有明确反馈。
- 下载按二进制流处理并保留中文原始文件名。
- 私有 URL 不进入持久化存储，过期后可以通过刷新恢复。
- 单个和批量删除均展示不可恢复影响，失败时不误报成功。

### 17.3 存储配置

- SecretKey 从不回显，编辑时必须重新输入。
- AccessKey 在列表中默认脱敏。
- endpoint 输入带协议时在字段级阻止提交或展示后端 422。
- 配置 key 冲突时保留表单并定位错误。
- 默认配置使用标签和“设为默认”动作，不使用可取消的行内开关。
- 设置默认只提交 ID 和状态，不夹带其他配置字段。
- 内置配置和当前默认配置不显示删除入口。
- 删除普通配置展示历史文件失联风险。

### 17.4 视觉、响应式与可访问性

- 页面遵循现有 Ant Design、UnoCSS 和 Skyroc 设计系统。
- 页面主操作唯一，危险操作使用 Error 语义且与普通操作分离。
- 1440px、1024px 和 768px 宽度下无关键操作遮挡。
- 键盘可以完成查询、上传选择、打开详情、下载和关闭弹窗。
- 状态不只依赖颜色，表单错误可被辅助技术识别。
