# CONFIG-001 Skyroc Admin 参数管理

## 1. 文档信息

- 页面族：系统管理 / 系统设置
- 页面路径：`/system/config`
- 适用终端：Web，桌面优先并兼容窄屏
- 优先级：P1
- 设计状态：原型设计
- 日期：2026-08-08

关联原型：`../../prototypes/config/index.html`  
当前 FastAPI 模块：`skroc-fast/app/modules/config/api/v1/routes.py`

## 2. 产品结论

参数管理用于维护租户级的键值配置。管理员可以按名称、键名、类型和创建时间定位参数，查看完整键值，新增或编辑参数，批量删除自定义参数，以及在配置变更后刷新缓存。参数键名是代码和缓存引用的稳定标识；参数值允许文本、数字、JSON 或开关字符串，因此列表中提供遮罩展示和一键查看详情。

页面采用“查询工具栏 + 参数表格 + 新增/编辑抽屉”的单工作区结构，不引入组织树。系统内置参数与自定义参数通过类型徽标区分，内置参数默认只读且不可删除。

## 3. 接口与权限

| 能力 | 接口 | 页面行为 | 权限/约束 |
| --- | --- | --- | --- |
| 分页列表 | `GET /system/config/list` | 查询、分页、排序 | 当前租户；接口暂由超级管理员门禁代管 |
| 导出 | `POST /system/config/export` | 导出当前筛选命中的全部数据 | xlsx 文件流，导出含完整键值 |
| 详情 | `GET /system/config/{configId}` | 打开编辑抽屉前获取最新数据 | 超级管理员 |
| 新增 | `POST /system/config` | 提交新增表单 | 键名格式、长度、租户内唯一 |
| 修改 | `PUT /system/config` | 提交完整表单 | 键名格式、长度、租户内唯一 |
| 按键更新 | `PUT /system/config/updateByKey` | 供快捷配置入口使用，不在首版主表暴露 | 只改键值 |
| 删除 | `DELETE /system/config/{configIds}` | 单个或批量删除 | 任一不存在或内置参数时整批失败 |
| 刷新缓存 | `DELETE /system/config/refreshCache` | 清理当前租户参数缓存 | 超级管理员；成功后 toast |

## 4. 数据字段

| 字段 | 类型/限制 | 展示与交互 |
| --- | --- | --- |
| `configId` | int | 表格隐藏列，详情中展示 |
| `configName` | 1-100 字符 | 参数名称，支持模糊查询 |
| `configKey` | 1-100 字符；写入需匹配 `^[a-zA-Z][a-zA-Z0-9_.-]*$` | 等宽字体展示，支持复制 |
| `configValue` | 1-500 字符 | 默认遮罩；点击“查看”打开详情 |
| `configType` | `Y` 内置 / `N` 自定义 | 内置参数显示锁定徽标，不允许删除 |
| `remark` | 最长 500 字符，可空 | 次级信息或详情字段 |
| `createTime` | ISO 格式字符串，可空 | 表格次级文本，支持创建时间范围筛选 |

## 5. 页面目标与信息架构

管理员完成一次配置维护的路径：

```text
系统设置 / 参数管理
  → 筛选参数
  → 查看键值或打开编辑抽屉
  → 提交 / 删除 / 导出
  → 需要时刷新租户缓存
```

页面区域：

1. 顶部面包屑、主题/通知入口和当前租户提示。
2. 页面标题与说明，右侧显示“缓存状态”和“刷新缓存”。
3. 查询区：参数名称、参数键名、类型、创建时间（更多筛选）以及查询/重置。
4. 工具栏：新增参数、批量删除、导出、刷新列表、列设置。
5. 表格：选择框、名称/备注、键名、键值、类型、创建时间、操作。
6. 新增/编辑抽屉：名称、键名、值、类型、备注；底部固定取消/保存。
7. 删除确认弹窗：显示数量和内置参数阻塞提示。

## 6. 关键交互

- 查询默认按 `createTime` 倒序；回车触发查询，重置清空条件并回到第 1 页。
- 键值超过 32 个字符时表格只显示前 12 个字符和省略号；“查看”展示完整值及复制按钮。
- 内置参数的编辑按钮保留，允许修改值；删除按钮禁用并以锁定图标说明原因。
- 未选择行时批量删除禁用；选择中包含内置参数时，点击批量删除弹窗先提示“提交将失败”，允许取消。
- 提交成功后关闭抽屉、刷新当前页并提示“新增成功/修改成功”；键名重复时保留表单并定位键名错误。
- 导出使用当前筛选条件，不带分页；下载中显示 loading，失败提示重试，不伪造下载成功。
- 刷新缓存成功后更新“刚刚刷新”时间；失败时提示“列表数据未受影响”。

## 7. 状态与异常

| 状态 | 页面反馈 |
| --- | --- |
| 加载中 | 表格骨架行，禁用查询按钮 |
| 空结果 | 空状态插画区域 + “清除筛选” |
| 无权限/401 | toast 提示并交由全局登录/权限守卫处理 |
| 键名重复 | 字段级错误“该键名已存在” |
| 内置参数删除 | 弹窗明确“内置参数不可删除” |
| 批量部分无效 | 整批失败，提示“未执行任何删除，请检查选择项” |
| 导出失败 | toast + 保留当前筛选条件 |
| 网络错误 | 表格保留旧数据，显示重试操作 |

## 8. 响应式与视觉

- 延续用户管理原型的 Skyroc Admin 设计：深色侧栏、浅灰页面背景、紫色主色、8px 控件圆角、弱边框容器。
- 桌面端主内容最大化利用宽度；表格最小宽度 980px，窄屏在容器内横向滚动。
- `<768px` 查询区单列，工具栏允许换行；抽屉占满屏幕，底部操作固定。
- 颜色不能只依赖色相表达状态：内置参数同时使用锁图标和“内置”文本，错误使用图标与文案。
- 所有图标按钮提供 `aria-label`；键值复制和删除等危险操作需有可见反馈。

## 9. 验收标准

- 能通过名称/键名/类型/创建时间组合查询，并正确重置分页。
- 新增、编辑、删除、批量删除、导出、刷新缓存均有明确的成功和失败反馈。
- 内置参数不能从任何删除入口提交；批量删除遵循整批原子失败语义。
- 编辑抽屉字段与接口请求体完全对应，键名校验在提交前完成。
- 原型在桌面和 768px 以下视口无布局溢出，表格可横向滚动。
