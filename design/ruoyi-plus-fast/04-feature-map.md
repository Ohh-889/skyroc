## 3. 账号与安全

### 3.1 登录

**用户目标**

安全、快速地进入有权访问的后台功能。

**功能**

- 账号密码登录。
- 表单校验。
- 登录中状态。
- 登录失败反馈。
- 原目标页面重定向。
- 登录成功后的用户和菜单初始化。

**待确认扩展**

- 图形验证码。
- 短信或邮箱验证码。
- 多因素认证。
- 第三方登录。
- 记住登录。

### 3.2 会话管理

- Token 刷新。
- 会话失效提示。
- 主动退出。
- 异常退出后的登录重定向。
- 多设备会话策略，待确认。

### 3.3 密码与账号恢复

- 忘记密码。
- 身份验证。
- 设置新密码。
- 修改成功后的会话处理。

是否进入首期取决于后端账号恢复方案。

## 4. 工作台

### 4.1 角色化概览

- 当前用户和角色信息。
- 角色相关关键指标。
- 权限或账号风险摘要。
- 系统公告或重要提示。

### 4.2 待办与风险

- 待处理事项。
- 失败或异常操作。
- 即将过期或需要关注的配置。
- 敏感权限变化。

### 4.3 快捷入口

- 常用功能。
- 最近访问。
- 由权限过滤后的可用入口。

### 4.4 近期操作

- 当前用户近期操作。
- 管理员关注的关键系统变更。
- 操作详情入口。

## 5. 组织与用户

### 5.1 用户管理

- 按姓名、账号、手机号、状态、角色和组织筛选。
- 查看用户列表和详情。
- 新增和编辑用户。
- 启用、停用和批量处理。
- 重置密码。
- 分配角色。
- 查看用户操作和登录记录。

具体字段以真实接口为准。

### 5.2 部门管理

- 查看组织树。
- 新增、编辑、移动和停用部门。
- 查看部门成员。
- 设置负责人。

是否需要移动部门和级联影响提示待确认。

### 5.3 岗位管理

- 岗位列表。
- 新增和编辑岗位。
- 启用和停用岗位。
- 查看岗位成员。

岗位是否参与权限计算待确认。

## 6. 角色与权限

### 6.1 角色管理

- 查看、筛选和搜索角色。
- 新增和编辑角色。
- 启用和停用角色。
- 查看角色成员。
- 分配菜单、页面和按钮权限。
- 设置数据范围。

### 6.2 权限配置

- 按模块展示权限。
- 支持父子权限联动。
- 区分页面访问和页面操作。
- 展示已选权限摘要。
- 保存前展示影响范围。
- 必要时支持复制角色权限。

### 6.3 数据范围

候选范围：

- 全部数据。
- 本部门及下级部门。
- 本部门。
- 仅本人。
- 自定义范围。

最终以真实后端模型为准。

## 7. 系统配置

### 7.1 菜单管理

- 菜单树。
- 目录、页面、按钮和外链等类型。
- 路径、标题、图标、排序和显示状态。
- 页面角色权限。
- 隐藏页面的活动菜单。
- 页签和缓存属性。

菜单字段需要与当前后端路由模型对齐，避免直接复制其他框架字段。

### 7.2 字典管理

- 字典类型。
- 字典项。
- 排序、状态和显示样式。
- 使用范围和影响提示。

### 7.3 参数配置

- 参数检索。
- 参数编辑。
- 敏感值保护。
- 变更前后记录。
- 生效范围和生效时间提示。

### 7.4 通知公告

- 公告列表。
- 草稿、发布和撤回。
- 可见范围。
- 发布时间。

是否进入首期待确认。

## 8. 日志与审计

### 8.1 操作日志

- 按用户、模块、操作类型、时间和结果筛选。
- 查看操作对象、请求摘要和结果。
- 查看变更前后值，取决于后端数据。
- 导出，待确认。

### 8.2 登录日志

- 登录用户、时间、设备、地址和结果。
- 登录失败原因。
- 风险标记。
- 与用户详情关联。

### 8.3 权限变更

- 角色权限变化。
- 用户角色变化。
- 数据范围变化。
- 变更人、时间和影响对象。

## 9. 个人中心

- 查看和编辑允许自助维护的资料。
- 修改密码。
- 查看登录设备或会话，待确认。
- 设置语言、主题和其他个人偏好。
- 查看本人登录和关键操作记录。

## 10. 跨模块公共能力

- 搜索、筛选和分页。
- 排序和列显示设置。
- 单条和批量操作。
- 导入导出，按模块确认。
- 加载、空数据、失败和无权限状态。
- 消息、通知和确认。
- 操作成功后的数据刷新。
- URL 中保留适合分享和返回的查询状态。
- 国际化。
- 明暗主题。

## 11. 功能依赖

| 功能         | 依赖                         |
| ------------ | ---------------------------- |
| 用户授权     | 用户、角色和权限模型         |
| 数据范围     | 组织模型和后端查询约束       |
| 角色化首页   | 用户角色、任务和真实数据     |
| 权限变更审计 | 权限写入和日志能力           |
| 菜单管理     | 后端动态路由协议             |
| 找回密码     | 邮箱或短信等身份验证渠道     |
| 登录风险     | 登录日志、设备和风险识别能力 |

## 12. 待确认事项

- 哪些功能进入首期。
- 用户、部门、岗位和租户之间的关系。
- 菜单、角色、按钮权限和数据范围的实际模型。
- 哪些操作支持批量处理。
- 哪些模块支持导入导出。
- 哪些日志可以展示变更前后值。
