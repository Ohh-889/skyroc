# 验收清单

## 1. 文件与格式

- [ ] PRD 位于约定路径，链接有效。
- [ ] 每个真实页面都有独立 `index.html`。
- [ ] 页面之间的相对链接指向存在的文件。
- [ ] Oxfmt 检查通过。
- [ ] 静态检查脚本通过。
- [ ] 没有遗留 `TODO`、模板占位符或真实敏感信息。

## 2. 内容一致性

- [ ] 页面数量与 PRD 页面清单一致。
- [ ] 查询字段、表格列、表单字段和状态与 PRD 一致。
- [ ] 当前 FastAPI 已实现与未实现能力没有混写。
- [ ] Java 参考能力已标明只是参考。
- [ ] 权限字符、接口路径和响应字段来自当前源码。
- [ ] 危险操作的影响和阻塞原因可见。

## 3. 浏览器尺寸

至少逐一检查：

- [ ] `1440 × 1000` 桌面端。
- [ ] `1024 × 768` 窄屏。
- [ ] `390 × 844` 手机端。

每个尺寸确认：

- [ ] 没有意外的页面级横向滚动。
- [ ] 固定区、抽屉和弹窗没有超出可视区域。
- [ ] 文字没有严重截断或覆盖。
- [ ] 主操作始终可发现。
- [ ] 手机端触控目标足够大。

## 4. 关键交互

根据页面实际能力检查：

- [ ] 查询、重置和更多筛选。
- [ ] 分页、刷新、列设置和批量选择。
- [ ] 新增、编辑、详情和保存校验。
- [ ] 浮层关闭、遮罩关闭和 Escape。
- [ ] 删除、停用、设为默认等危险确认。
- [ ] 成功、错误和警告反馈。
- [ ] 明暗主题或密度切换（页面提供时）。
- [ ] 跨页面相对链接。

## 5. 浏览器技术检查

- [ ] 控制台没有未处理异常。
- [ ] 本地资源没有 404。
- [ ] 所有图标和图片可见，失败时有降级。
- [ ] 焦点样式可见，Tab 顺序基本合理。
- [ ] 抽屉和弹窗有可访问名称。
- [ ] `prefers-reduced-motion` 下没有强制大动画。

## 6. 截图证据

每个页面至少保存：

- [ ] 桌面端主页面。
- [ ] 一个关键抽屉或弹窗。
- [ ] 手机端主页面或关键任务。

截图默认放在对应原型目录的 `qa/` 下，使用能表达内容的文件名，例如：

```text
qa/file-list-desktop.png
qa/upload-drawer.png
qa/file-list-mobile.png
```

截图只能证明视觉状态，不能替代真实点击、控制台和接口验证。
